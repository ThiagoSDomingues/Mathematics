LOGICAL SYSTEMS: CLASSICAL AND NON-CLASSICAL FRAMEWORKS  

1. LOGICAL PLURALISM

Logical pluralism is the view that there is no uniquely correct logic. Instead, multiple logical systems coexist, each appropriate for different domains of reasoning, inference, and modeling.

Key idea:
Different consequence relations may be equally valid depending on the context. Formally, a logic is defined by a consequence relation:
Γ ⊢ φ
which specifies when a conclusion φ follows from premises Γ.

Pluralists argue that:
- Classical logic is not universally adequate.
- Alternative logics capture reasoning patterns that classical logic cannot.
- Correctness is relative to purpose (e.g., mathematics vs. natural language vs. inconsistent databases).

Contrast:
- Logical monism: There is exactly one correct logic (typically classical logic).
- Logical nihilism: There is no correct logic.

Motivation:
- Semantic paradoxes (e.g., liar paradox).
- Vagueness (sorites paradox).
- Inconsistent but useful theories (e.g., early scientific models, inconsistent databases).

2. CLASSICAL LOGIC

Classical logic (CL) is the standard formal system underlying most of mathematics and theoretical computer science.

2.1 Semantics

Truth values:
- {0, 1}, where 1 = True, 0 = False.

Valuation function:
v: Prop → {0,1}

Connectives:
- Negation: v(¬A) = 1 − v(A)
- Conjunction: v(A ∧ B) = min(v(A), v(B))
- Disjunction: v(A ∨ B) = max(v(A), v(B))
- Implication: v(A → B) = max(1 − v(A), v(B))

2.2 Core Principles

Law of Bivalence:
Every proposition has exactly one truth value:
v(A) ∈ {0,1}

Law of Excluded Middle:
A ∨ ¬A is always true.

Law of Non-Contradiction:
¬(A ∧ ¬A) is always true.

Principle of Explosion (Ex Falso Quodlibet):
From a contradiction, anything follows:
A, ¬A ⊢ B

Example:
If a database contains both “x = 1” and “x ≠ 1”, then any statement becomes derivable in classical logic.

2.3 Strengths and Limitations

Strengths:
- Mathematically robust.
- Well-understood proof theory and semantics.
- Foundation for most formal sciences.

Limitations:
- Cannot tolerate inconsistency.
- Cannot model vagueness.
- Cannot express modalities (necessity, possibility) directly.

3. NON-CLASSICAL LOGICS

Non-classical logics modify or extend classical logic by altering its semantics, inference rules, or truth structures.

They typically relax one or more of:
- Bivalence
- Non-contradiction
- Explosion
- Truth-functionality

3A. PARACONSISTENT LOGIC

Paraconsistent logic rejects the principle of explosion.

3A.1 Core Idea

Contradictions do not trivialize the system:
A, ¬A ⊬ B

Thus, inconsistent theories can remain non-trivial.

3A.2 Semantics

Many systems use multi-valued semantics. A common example:
Truth values:
- T (true)
- F (false)
- B (both true and false)

In such systems:
v(A ∧ ¬A) can be non-zero without implying arbitrary conclusions.

3A.3 Example Systems

- Priest’s Logic of Paradox (LP)
- da Costa’s C-systems (Brazilian contribution, highly relevant historically)
- Relevant logics (related but distinct)

3A.4 Applications

- Inconsistent databases
- Legal reasoning (conflicting laws)
- AI knowledge bases
- Early-stage scientific theories

Example:
A medical database may contain conflicting diagnoses; paraconsistent logic allows reasoning without discarding all conclusions.

- 0 = completely false

- Conjunction: v(A ∧ B) = min(v(A), v(B))
- Disjunction: v(A ∨ B) = max(v(A), v(B))

Temperature classification:

- Control systems (ABS, HVAC)
- Image processing
- Decision-making systems
- Pattern recognition

3C. MODAL LOGIC

Modal logic extends classical logic with operators expressing modality.

3C.1 Syntax

- □A: Necessarily A
- ◇A: Possibly A

3C.2 Semantics (Kripke Models)

A model consists of:
- A set of worlds W
- Accessibility relation R ⊆ W × W
- Valuation function V

Truth conditions:
- □A is true at world w if A is true in all accessible worlds.
- ◇A is true at w if A is true in at least one accessible world.

3C.3 System Variants

Different modal systems impose constraints on R:

- K: minimal system
- T: reflexive (□A → A)
- S4: reflexive + transitive
- S5: equivalence relation (used in epistemic logic)

3C.4 Applications

- Program verification (temporal logic)
- Epistemic logic (knowledge and belief)
- Metaphysics (necessity and possibility)
- Multi-agent systems

Example:
□P: “This law holds in all physically possible universes.”
◇P: “This configuration is achievable.”

4. ADDITIONAL NON-CLASSICAL SYSTEMS (IMPORTANT EXTENSIONS)

4.1 Intuitionistic Logic

Rejects Law of Excluded Middle.

Key idea:
Truth = provability.

A ∨ ¬A is not universally valid unless constructively proven.

Applications:
- Constructive mathematics
- Type theory
- Programming language semantics

4.2 Relevant Logic

Rejects explosion and enforces relevance between premises and conclusions.

A → B is only valid if A is relevant to B.

4.3 Temporal Logic

Adds time operators:
- G A: always in the future
- F A: eventually
- X A: next state

Used in:
- Model checking
- Dynamical systems

5. COMPARATIVE OVERVIEW

Classical Logic:
- Truth values: {0,1}
- Explosion: yes
- Handles vagueness: no
- Use: mathematics, formal proofs

Paraconsistent Logic:
- Truth values: multi-valued (often)
- Explosion: no
- Handles inconsistency: yes
- Use: inconsistent systems, AI

Fuzzy Logic:
- Truth values: 
- Explosion: not central
- Handles vagueness: yes
- Use: control systems, engineering

Modal Logic:
- Truth values: {0,1} + structure
- Adds: necessity/possibility
- Use: philosophy, CS, verification

Intuitionistic Logic:
- Rejects excluded middle
- Truth tied to proof
- Use: constructive math

6. CONCEPTUAL CONNECTIONS

- Classical logic is a special case of many non-classical systems.
- Fuzzy logic generalizes truth values.
- Paraconsistent logic modifies inference rules.
- Modal logic enriches semantic structure (possible worlds).
- Intuitionistic logic reinterprets truth epistemically.

These systems can be combined:
- Fuzzy modal logic
- Paraconsistent modal logic
- Temporal fuzzy systems
